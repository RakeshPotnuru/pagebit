# Pagebit website

This directory is deployed to the Netlify project `pagebit` at `https://pagebit.publishstudio.one/`. Cloudflare has a DNS-only CNAME for `pagebit.publishstudio.one` pointing to `pagebit.netlify.app`. The project was deployed from this directory without a Git connection, so future changes need another deploy. No build or runtime is needed.

Use `https://pagebit.publishstudio.one/privacy/` in the Chrome Web Store privacy policy field. The landing page links to the published extension at `https://chromewebstore.google.com/detail/imfnpdoblfnacegdlnamflmelmeanoon`.

The privacy policy reflects the extension source as of 30 September 2026. Review its claims if the extension changes or if the hosting service adds analytics, cookies, or other data processing.
