# Running project scripts

Use Grove MCP tools to run this project's scripts. Use `grove_list_scripts` to find
a script, `grove_run_script` for commands that finish, and `grove_start_script`
for long-running or interactive commands. For interactive prompts, read output
with `grove_get_logs` and answer with `grove_send_input`.

Use a shell for one-off commands that are not project scripts.
